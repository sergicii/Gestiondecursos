# TecDev - Gestión de Cursos

Sistema web para administrar el catálogo académico del Instituto TecDev, especializado en la gestión de cursos de extensión.

## Instituto TecDev
Centro de formación tecnológica dedicado a cursos de especialización y extensión académica con enfoque práctico e innovador.

## Propósito del proyecto
Desarrollo progresivo de una aplicación web moderna para administración del catálogo de cursos académicos, con arquitectura por capas:

- diseño base en HTML + CSS
- fundamentos con JavaScript moderno y TypeScript
- panel administrativo con Angular
- API REST con Node.js + Express + MongoDB
- portal de consulta en React
- landing pública en Next.js
- despliegue y seguridad al cierre del ciclo

## Funcionalidades principales
- Listado de cursos con filtros
- Registro de nuevos cursos
- Edición de información de cursos
- Visualización de detalle de cursos
- Validación de datos
- Navegación por rutas
- Consumo de API REST simulada

## Atributos de cada curso
- ID único
- Nombre del curso
- Categoría académica
- Docente encargado
- Modalidad (presencial/virtual/híbrida)
- Duración en horas
- Vacantes disponibles
- Costo de inscripción
- Fecha de inicio
- Estado activo (sí/no)
- Descripción del contenido

## Usuario principal
Coordinador académico que requiere administrar eficientemente el catálogo inicial de cursos de la institución.
